Count only what a user can see and tap when a quoted Tap or Fill names several elements: a same-label wrapper with no handler of its own counts as the control it wraps, a duplicate whose whole frame is off screen, clipped or under the keyboard is set aside, and on iOS up to four identifiable duplicates get a live hit read. Ambiguity refusals name which candidate is nested inside which and every candidate set aside with its reason, refusals name what covers a target, and step rows record `collapsed`, `candidateExclusions` and `coveredBy`.
